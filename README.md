## 1. Glossary

| Term | Meaning |
|---|---|
| Slat | Horizontal profile that forms the shutter curtain |
| Side track / guide | Vertical channel the slats run in on each side of the opening |
| Pelmet | Box at the top of the opening that houses the rolled-up curtain |
| Manual operation | Raised and lowered by hand |
| Motorised / electric | Raised and lowered by a motor |
| Powdercoat | Durable coloured finish applied to aluminium |
| Made to measure | Built for the exact dimensions of each opening |
